# 简截 v1.0.4 发布说明

> 这份内容与 GitHub Releases 页面上的正文一致。

两个体验问题：**截图中找不到鼠标**，以及**悬停窗口时那个绿框很碍事**。

## 1. 加了个光标准星

压暗整屏之后，系统那个细十字光标在花哨的背景上很容易看丢。现在光标外面多了一圈
「圆环 + 四向短线」的准星：

- 白色描边打底、黑色阴影勾边，深色浅色背景都压得住
- 中间留空，系统十字光标正好落在环心，不影响精确对准
- 只画在覆盖层上，**不会进入截图结果**
- 光标移到工具条或结果面板上时自动隐藏，不叠加两套图形

拖拽选区时不画准星 —— 那时候放大镜已经在旁边了。

## 2. 去掉悬停窗口的绿框

以前光标停在一个窗口上，会沿着窗口边缘画一圈 2px 绿框，右上角还标着尺寸
（比如「974 × 844」）。这个框是「单击直接截整个窗口」的提示，但实际用起来
更像是画面上的噪音，尤其在大窗口上会占满半个屏幕。

现在这层提示完全去掉了，画面只剩准星和放大镜。
**单击空白处仍然可以整窗截取**，功能没动，只是不再提前画出那个框。

## 顺手清理

`magPos` / `magValid` 这两个字段原本只为放大镜服务，现在改成每帧直接
`GetCursorPos` 取光标位置，它们就没人用了，一并删掉。
顺带在 `WM_MOUSELEAVE` 里补上清理悬停态，光标离开时工具条不会留着高亮。

## 验证

- 6 个回归脚本全过（重复截图 / 选区工具条 / 7 种标注 / 放大镜贴图翻译 / 保存 / 面板布局）
- OCR 压测 4 轮，无崩溃
- 截图确认：待机状态下准星可见、窗口绿框消失；拖选时准星消失、放大镜出现
- Ctrl+C 出来的剪贴板图仍是 600×300（准星没有被画进结果里）

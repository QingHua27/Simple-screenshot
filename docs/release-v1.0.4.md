# 简截 v1.0.4 发布说明

> 这份内容与 GitHub Releases 页面上的正文一致。

三个体验问题：**截图中找不到鼠标**、**光标样式太花**、**悬停窗口时那个绿框很碍事**。

## 1. 光标换成蓝色箭头

压暗整屏之后，系统那个细十字光标在花哨的背景上很容易看丢。这次干脆把覆盖层
里的光标整个换掉：

- macOS 风格的蓝色箭头，左上偏亮、右下偏深的渐变，加一圈极淡的深蓝描边，
  浅色深色背景都压得住
- **箭头尖就是落点**，定位手感和平时用鼠标一样
- 不是每帧画在画布上的，而是做成真正的光标（`HICON` + `SetCursor`），
  由系统合成，移动零延迟，也**不会出现在截图结果里**
- 拖控制点、拖整个选区时仍然给系统的缩放 / 移动光标 —— 方向感比箭头清楚
- 顺带修了个老毛病：以前拉选区时，光标一直压在刚拖出来的那个角上，会被判定成
  控制点，缩放箭头甩都甩不掉。现在按拖拽状态分流，拖选中就是箭头

## 2. 去掉悬停窗口的绿框

以前光标停在一个窗口上，会沿着窗口边缘画一圈 2px 绿框，右上角还标着尺寸
（比如「974 × 844」）。这个框是「单击直接截整个窗口」的提示，但实际用起来
更像是画面上的噪音，尤其在大窗口上会占满半个屏幕。

现在这层提示完全去掉了，画面只剩光标和放大镜。
**单击空白处仍然可以整窗截取**，功能没动，只是不再提前画出那个框。

## 顺手清理

- `magPos` / `magValid` 这两个字段原本只为放大镜服务，现在改成每帧直接
  `GetCursorPos` 取光标位置，它们就没人用了，一并删掉
- 在 `WM_MOUSELEAVE` 里补上清理悬停态，光标离开时工具条不会留着高亮

## 验证

- 6 个回归脚本全过（重复截图 / 选区工具条 / 7 种标注 / 放大镜贴图翻译 / 保存 / 面板布局）
- OCR 压测 4 轮，无崩溃
- 逐帧截图确认：待机、拖选、工具条上都是蓝箭头；选区内部是移动光标；控制点是缩放光标
- Ctrl+C 出来的剪贴板图仍是 600×300（光标没有被画进结果里）

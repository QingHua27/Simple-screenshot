# 简截 v1.0.1 发布说明

> 这份内容与 GitHub Releases 页面上的正文一致。

修一个界面遮挡问题，功能与 v1.0.0 相同。

## 修复

**「提取文字 / 翻译」的结果面板会压住工具条**，导致工具条右半边（撤销、保存、复制、贴图、取消）
被面板盖住，点不到也看不清。

原因：面板固定放在选区右侧，工具条固定放在选区下方且宽度有 562 px，
选区小的时候两者水平方向必然相交。

改法：面板改成**多候选位置打分选优**——

1. 先按「选区右侧 → 左侧 → 下方 → 上方 → 右侧但避开工具条」生成候选；
2. 每个候选按「出界距离」和「是否压住工具条」打分，取最优；
3. 侧边候选如果只是被工具条压住一点点，优先**水平挪到工具条外侧**，
   而不是整块面板被迫下移；
4. 工具条也做了反向避让：面板开着时移动选区，工具条会翻到选区另一侧。

修复前后（同一个 155×32 的小选区）：

| 修复前 | 修复后 |
|---|---|
| 面板 (425, 6) 压住工具条右半 | 面板 (668, 40)，与选区顶端对齐、让开工具条 |

# 简截 v1.0.3 发布说明

> 这份内容与 GitHub Releases 页面上的正文一致。

**把工具条改成微信截图的样子。** 只动外观和布局，功能一个没少。

## 改了什么

原来的工具条是深色底、圆角块、图标偏粗。这一版按微信截图的视觉重做：

- **浅色底** `#FAFAFA` + 1px 浅灰描边 + 6px 圆角，浮在压暗的桌面上反而更清楚
- **图标统一成 1.5px 细线**，颜色 `#4C4C4C`，全部按 20×20 的虚拟画布描点再等比缩放
- **三组分隔**：标注工具 / 文字处理 / 操作，组间一根 `#E0E0E0` 竖线
- **顺序对齐微信**：矩形、椭圆、箭头、画笔、马赛克、文字、序号 ｜ 翻译、提取文字、标注颜色 ｜
  撤销、保存、贴图、复制、取消、完成
- **状态色**：选中的工具是浅绿底 `#E8F8EF` + 绿色图标，悬停是 `#EEEEEE`；
  取消用微信红 `#FA5151`，完成用绿 `#00C375`
- **新增「完成」按钮**（绿 ✓）—— 和回车一样，复制到剪贴板并退出
- **撤销会自动置灰** —— 没有标注时是 `#D0D0D0`，有东西可撤才变深
- 格宽 44、条高 48、分隔 16，和微信截图的比例基本一致（它 48/53，这里 44/48）

顺带把**结果面板**也换成了同一套浅色（白底、深灰字、浅灰次要按钮），
否则白工具条旁边挂一块黑面板太割裂。

## 顺带修的

`build_cpp.bat` 之前会在 `rc.exe` 那一步静默失败：批处理按 OEM 代码页（936）解析，
文件里 UTF-8 的中文注释末尾有个字节把 CRLF 吃掉了，下一行命令被吞进注释里。
表现是 `rc` 根本没执行、`app.res` 用的是上一次的旧文件，但整体还报 `EXITCODE=0`。
现在整个脚本改成纯 ASCII 注释，并且加了 `app.res` 是否真的生成的检查。

## 验证

- 6 个回归脚本全过（重复截图 / 选区工具条 / 7 种标注 / 放大镜贴图翻译 / 保存 / 面板布局）
- OCR 压测 6 轮 × 6 个不同位置选区，无崩溃
- 点「完成」实测：剪贴板拿到 740×220 的图，覆盖层正常退出
- 撤销按钮的置灰 → 变深，画一个矩形前后各截了一张确认
- 按钮坐标不再写死在测试里，统一由 `cpp/tests/tbgeom.py` 算

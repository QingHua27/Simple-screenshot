# 简截 v1.0.0 发布说明

> 这份内容与 GitHub Releases 页面上的正文一致。

微信截图（`Alt+A`）交互的独立复刻版，**不需要登录微信**。

冻结屏幕 → 拖拽或单击框选窗口 → 放大镜取色 → 标注 → 提取文字 / 翻译 → 复制 / 保存 / 贴图。

- **系统要求**：Windows 10 / 11 64 位
- **不需要**装 .NET 或 VC 运行库（`/MT` 静态链接 CRT）
- 启动后托盘出现绿色图标；默认热键 `Alt+A`，被其它程序占用时会自动降级到 `Alt+Z`、`Ctrl+Alt+A` 等，具体看托盘菜单里打勾的那一项

> 绿色软件，不写注册表（只有勾选「开机自动启动」时才写一条 `Run` 项）。
> 配置在 `%APPDATA%\JianJie\settings.json`，日志在 `%LOCALAPPDATA%\JianJie\app.log`。

## 功能

**截图**

- 全屏冻结，拖拽框选；单击则直接选中光标下的窗口（自动识别窗口边界，跳过桌面和隐藏窗口）
- 选区 8 个控制点可调整，方向键微调（按住 `Shift` 步进 10 px）
- 放大镜：7 倍放大 + 十字线 + `RGB` / 坐标实时读数，取色很准

**标注**

- 矩形、椭圆、箭头、画笔、马赛克、文字、序号，共 7 种
- 6 色调色板，`C` 键循环切换；`Ctrl+Z` 撤销
- 马赛克是「降采样 → 放大」得到像素块，再按笔迹路径裁剪，不是简单涂灰
- 文字标注是内联编辑，支持中文输入法（自己画光标和候选串，不走子窗口）

**提取文字 / 翻译**

- OCR 走系统自带的 `Windows.Media.Ocr`，**完全离线**，中英文都能识别
- 翻译默认用免费的 MyMemory 接口；也可以在托盘菜单「翻译服务…」里填一个 OpenAI 兼容的接口（DeepSeek、通义、本地 Ollama 都行），质量更好
- 结果面板可滚动，能一键切原文 / 译文对比

**输出**

- `Enter` 复制到剪贴板，同时写 `CF_DIB` 和 `PNG` 两种格式，贴到微信 / QQ / Word 都不会糊
- `Ctrl+S` 另存为，`Ctrl+T` 贴图置顶（可拖动、滚轮缩放、右键菜单），`Esc` 取消

## 从源码构建

产物在 `cpp/build/JianJie.exe`。仓库里也保留了 Python + PySide6 版本（`src/`），

## 已知限制

- 仅 Windows 10 / 11；OCR 依赖系统已安装的语言包
- 免费翻译接口有频率限制，短时间连续翻译会返回 `HTTP 429`，等一会儿或改用大模型接口
- 没做长截图和录屏
- 若微信正在运行，`Alt+A` 会被微信抢走 —— 这是系统级热键的独占特性，换个组合即可
